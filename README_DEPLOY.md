# Embedded Circuit Studio

This is a static website. Deploy the contents of this folder as the public web root.

## Quick Hosting Options

- Netlify: drag this folder into Netlify Drop, or connect the folder/repo with `publish = "."`.
- Vercel: import the folder/repo as a static project. `vercel.json` is included.
- GitHub Pages: publish this folder from a repository branch as a static site.

No backend is required. The circuit designer, wire simulation, and code simulator run in the browser.
